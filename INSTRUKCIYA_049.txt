«ПЬЯНЫЙ ПЕТУХ 0.49» — ИНСТРУКЦИЯ (3 шага)

ЧТО ПОЧИНЕНО В 0.49 (найдено по коду, причины «смерти» игры):
  1. GetMouse() — вызывался БЕЗ защиты в конструкторах слайдеров и
     колорпикера. На части экзекуторов (Solara/Delta/Xeno) он БЛОКИРУЕТ
     поток до спавна игрока: инжект чуть раньше спавна = FPS 0 = игра
     умирает НА СЛУЧАЙНОМ ЭТАПЕ (как у тебя и было). В 0.49 GetMouse не
     вызывается ВООБЩЕ.
  2. КАЖДЫЙ слайдер/колорпикер/кейбинд вешал свои ГЛОБАЛЬНЫЕ соединения
     ввода (120+ вечных колбэков при 40+ элементах) — каждый тап и каждый
     кадр прогонял их все. Теперь 4 соединения на всю библиотеку.
  3. Прямой парентинг в CoreGui убран отовсюду (ещё одна причина
     мёртвых зависаний на мобильных экзекуторах). Только gethui/PlayerGui.

(старый лоадер 0.48 покажет предупреждение о версии — так тоже видно, что
старый не забыл заменить).

ШАГ 2. Залей на GitHub в репозиторий GalinDeonor/Beta файлы из этой папки:
  manifest.json, Fust1, Fust2, Fust3, Fust4, Fust5
  (Fust — целиком, по желанию; это тот же код одним файлом)
  Старые Fust1..Fust5 и manifest.json от 0.48 заменятся при загрузке.
  (GitHub: репо -> Add file -> Upload files -> перетащи -> Commit)

ШАГ 3. Подожди ~5 минут (кэш GitHub) и запусти лоадер в игре.

  (клавиша меню в Настройках) тоже должны переназначаться.
