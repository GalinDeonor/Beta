ПЬЯНЫЙ ПЕТУХ 0.47 — NEVERLOSE UI (полная смена библиотеки)

ПОЧЕМУ: LiquidGlass вешала исполнителя после плашки в 0.44/0.45/0.46.
Причина — 1.0 МБ библиотека с внутренними сетевыми вызовами и тяжёлым
парсингом на слабых телефонах. Neverlose UI — 76 КБ, ноль сетевых вызовов.

ЧТО СДЕЛАНО (патчи P1-P14 к Neverlose):
  P1   Dragify + Touch (drag окна пальцем)
  P2   безопасный parent: gethui() -> CoreGui -> PlayerGui (pcall)
  P3   починен Library:Toggle (оригинал звал несуществующий метод)
  P4   Slider: options.default (стартовое значение) + позиция через
       InputChanged (палец/мышь) — touch-совместимо
  P5   Colorpicker: MouseMoved -> UserInputService.InputChanged (touch)
  P6   ВСЕ элементы возвращают объект Set/Get/SetText/SetVisible/
       Destroy/Fire — нужно для системы конфигов LoadConfig
  P7   добавлены элементы Label и Paragraph (в Neverlose не было)
  P8   Dropdown: режим Multi (галочки, callback получает таблицу) +
       фикс падения на Default-таблице
  P9   красная тема бренда (13 замен RGB: синий -> красный FUST)
  P10  Window возвращает SG/Body/SetVisible для управления
  P11  Section.Frame наружу — вайтлист-панель и cfgStatus теперь ВИДНЫ
       (в LiquidGlass-версии они были спрятаны заглушкой!)
  P12  Keybind: onkeychanged-хук при переназначении клавиши
  P13  компактные вкладки (11 табов Fust влезают в сайдбар)
  P14  Keybind default строкой ("RightControl"), не только EnumItem
  +    deprecated :connect -> :Connect
